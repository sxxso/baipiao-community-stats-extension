# 白嫖社区个人统计

一个独立的 Chromium Manifest V3 浏览器插件，用于查看当前登录的白嫖社区账号资料、社区统计、毛余额、社区等级、最近活动和资金记录。

资金记录会在白嫖社区页面右下角显示为一个小窗口：可以刷新、收起和重新展开，也可以打开网站的完整资金记录页面。插件只做读取，不执行发帖、回复、点赞、收藏、私信、转账或其他会改变社区状态的操作。

- [下载 Chrome 版](https://github.com/sxxso/baipiao-community-stats-extension/releases/latest/download/baipiao-community-stats-extension-chrome.zip)

## 安全性与隐私

请在安装前阅读本节。这个插件会读取你当前登录账号在白嫖社区页面中已经可以看到的个人信息和资金信息，因此建议只从可信来源下载，并核对扩展权限。

### 插件申请的权限

| 权限 | 用途 |
| --- | --- |
| `storage` | 在当前浏览器本地保存归一化后的统计快照、最多 5 条资金记录和窗口状态。 |
| `tabs` | 查找或打开白嫖社区页面，以便读取数据。 |
| `scripting` | 在白嫖社区页面中补充注入读取脚本，处理页面尚未注入内容脚本的情况。 |
| `https://baipiao.org/bbs/*` | 只允许插件访问白嫖社区 BBS 页面。 |

插件**没有**申请以下权限：

- `cookies`
- `<all_urls>`
- `webRequest`
- `history`
- 远程代码或 CDN 脚本权限

### 数据边界

- 不读取 `document.cookie`，不读取密码输入框，不读取网站的 `localStorage`。
- 不保存或上传密码、Cookie、Authorization、Token、完整 HTML 或原始响应内容。
- 读取社区数据的请求只发往 `https://baipiao.org/bbs/` 同源页面，并复用浏览器当前已经建立的登录会话；不会向第三方域名发送账号数据。
- 新版本检查是唯一的例外：插件会节流访问 GitHub 公开接口 `api.github.com` 读取本仓库的最新 Release 号，不携带任何账号、Cookie 或社区数据；检查结果只保存在浏览器本地。
- 插件只保存归一化后的必要字段：用户名、头像地址、称号、注册和活跃时间、主题数、回复数、毛余额、社区等级、最多 5 条最近活动和最多 5 条资金记录；以及毛排行榜的前 10 名（排名、用户名、余额、主页链接）和当前账号自己的名次。排行榜只保留社区公开榜单已展示的字段，不保存头像、原始响应或其他可识别信息。
- 数据保存在浏览器的 `chrome.storage.local` 中，不会上传到 GitHub 或插件作者的服务器。浏览器本地存储不是加密保险箱，请不要在不受信任的共享浏览器配置中使用。
- 卸载插件或在浏览器扩展管理页清除插件数据，可以删除本地缓存。网站本身的登录状态不由本插件管理。

### 安装前的安全检查

从 GitHub 下载或接收别人转发的压缩包后，请先解压并打开第一层的 `manifest.json`，确认：

1. `permissions` 只有 `storage`、`tabs`、`scripting`。
2. `host_permissions` 只有 `https://baipiao.org/bbs/*`。
3. 没有出现 `cookies`、`<all_urls>`、`webRequest` 或陌生域名。
4. 扩展目录中没有要求你填写密码、Cookie、Token 或私钥的脚本和说明。

如果后续版本突然要求上述额外权限，先不要批准，检查代码变更和发布说明后再决定是否安装。

## 功能

点击浏览器工具栏中的插件图标，可以查看：

- 当前登录用户的头像、用户名、称号、加入时间和个人主页。
- 主题数、回复数、毛余额和社区等级。
- 毛排行榜前 10 名和当前账号自己的名次。
- 最近 7 天活跃趋势和最近活动。

在白嫖社区页面右下角，可以查看：

- 最近 5 条资金记录。
- 每条记录的资金用途、时间和余额增减。
- 当前毛余额。
- 毛排行榜前 5 名和自己的名次，并可打开完整排行榜页面。
- 刷新、收起、展开和“查看全部”。

资金记录页本身不会再次注入右下角浮窗，避免重复显示。

## 安装使用

### 从 GitHub 下载

1. 在本 README 顶部选择 Edge 版或 Chrome 版下载；推荐使用 Release 附件，不要下载错误的项目外层目录。
2. 将 ZIP 解压到一个固定目录。不要直接在压缩包内加载插件。
3. 确认解压后的目录第一层直接包含 `manifest.json`。

如果使用 GitHub 仓库页面的 `Code` → `Download ZIP`，GitHub 自动下载的源码包通常会多包一层仓库目录；请继续进入内层，直到打开目录后能直接看到 `manifest.json`、`background.js`、`content.js` 和 `popup.html`。Release 附件没有这一层目录。

### Edge

1. 打开 `edge://extensions/`。
2. 开启右上角的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择上一步找到的、第一层直接包含 `manifest.json` 的目录。
5. 打开或刷新 `https://baipiao.org/bbs/`，确认已经登录。
6. 点击 Edge 工具栏中的插件图标；需要经常使用时，可以将插件固定到工具栏。

如果 Edge 提示“找不到清单文件”，通常是目录选错：不要选择 ZIP 文件、下载目录、仓库外层目录或项目工作区，继续进入内层直到看到 `manifest.json`。

### Chrome

1. 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择第一层直接包含 `manifest.json` 的目录。
5. 登录并打开 `https://baipiao.org/bbs/`，然后点击插件图标。

### 更新插件

插件内置了新版本提示，无需自己盯着 GitHub：

1. 插件启动和每次手动刷新数据时，会节流（约每 6 小时一次）检查 GitHub 上的最新 Release。
2. 发现新版本时，弹窗顶部会出现“发现新版本”横幅，点击“前往下载”直接打开发布页。
3. 点击“知道了”可以忽略当前版本的提示，直到下一个新版本再出现。

由于浏览器限制，“加载解压缩的扩展”无法被插件静默替换文件，升级仍需：

1. 下载新版本并解压到新的目录。
2. 在扩展管理页删除旧版本，或者在旧扩展卡片上点击“重新加载”。
3. 加载新版本目录。
4. 刷新已经打开的白嫖社区页面。

内容脚本是在网页加载时注入的，只在扩展管理页重新加载而不刷新网页时，右下角窗口可能仍然显示旧版本。如果希望完全自动的后台更新，需要把扩展上架到 Edge 加载项或 Chrome 应用商店，由商店完成静默升级；本仓库当前仅提供 GitHub 发布与插件内提示。

## 使用说明

### 刷新规则

- 打开插件弹窗时只读取浏览器本地缓存，不会自动请求最新数据。
- 需要更新数据时，点击弹窗右上角的刷新按钮。
- 刷新时会重新读取当前账号资料、主题、回复、毛余额、社区等级、最近活动、资金记录和毛排行榜。
- 毛余额优先读取当前登录用户接口 `/bbs/api/users/<用户ID>` 的 `money` 字段；如果接口暂时不可用，则保留页面内嵌用户数据中的余额作为回退。管理员调账即使没有对应资金流水，也会以用户接口返回值为准。
- 毛排行榜来自站点榜单接口 `/bbs/api/money-rank`，在任何社区页面刷新都能获取，不需要先打开排行榜页；接口暂时不可用时会保留上次成功读取的榜单。
- 最近活动来自白嫖社区的帖子接口（与个人主页帖子列表同源），无论当前停留在哪个社区页面，点刷新都可以获取，不需要先打开个人主页。
- 个别情况下帖子接口暂时不可用时，插件会回退读取已渲染完成的个人主页活动节点；此时需要先打开个人主页。

### 弹窗显示“读取超时”

白嫖社区响应较慢时，插件会保留上次成功读取的数据。可以按以下顺序处理：

1. 确认当前账号已经在白嫖社区登录。
2. 先直接打开并刷新 `https://baipiao.org/bbs/` 或个人主页，等待页面完成加载。
3. 刷新扩展管理页中的插件，再刷新社区网页。
4. 点击插件弹窗右上角的刷新按钮。打开弹窗本身不会触发新的读取请求。

### 资金记录没有显示

资金记录通过白嫖社区的资金记录接口读取，在任何社区页面刷新浮窗都可以获取，不需要先打开资金记录页。若仍为空：

- 确认当前页面属于 `https://baipiao.org/bbs/`。
- 确认个人主页能正常打开，且账号可以在网站中看到自己的资金记录。
- 重新加载扩展并刷新网页。
- 点击“查看全部”确认网站原始资金记录页是否有数据。

网站调整页面结构后，插件可能需要更新解析规则；插件显示的是网站当前页面可读取到的数据，不会自行推测缺失字段。

## 数据来源

插件优先读取白嫖社区当前使用的 Flarum 页面数据：

- 从页面内嵌的 `script#flarum-json-payload` 识别当前会话用户和社区资源。
- 从页面内嵌的用户资源读取基础资料和回退余额；刷新时再通过当前用户接口（`/bbs/api/users/<用户ID>`）读取权威的 `money` 字段。该字段不依赖资金流水，能够覆盖管理员调账等未记录为交易的变化。
- 从论坛资源的 `bpMyLevel` 和 `bpLevelNames` 映射社区等级。
- 通过 Flarum 帖子接口（`/bbs/api/posts`，按当前登录账号过滤，与个人主页帖子列表同源）读取最近主题和回复；接口不可用时回退读取已渲染的个人主页活动节点。
- 通过资金记录接口（`/bbs/api/users/<用户ID>/money/history`，与资金记录页同源）读取最近交易；接口不可用时回退读取资金记录页已渲染的记录节点。资金流水只用于展示记录，不用于推算当前毛余额。
- 通过毛排行榜接口（`/bbs/api/money-rank`，与 `/bbs/money` 页面同源）读取榜单前若干名、当前账号名次和全站有毛的账号总数；插件只保留排名、用户名、余额和主页链接，最多展示前 10 名。

旧接口探测只作为兼容性兜底。缺失或无法确认的数据显示为 `—`，不会用页面条目数量冒充接口统计。

## 发布前检查

发布新版本前，建议至少执行：

```powershell
npm test
npm run check
git diff --check
```

并检查以下内容：

- `manifest.json` 没有新增不必要权限。
- 仓库中没有 Cookie、密码、Token、Authorization、个人资金截图或真实账号数据。
- 压缩包根目录可以直接看到 `manifest.json`，或者在 README 中明确指出正确的内层目录。
- 代码只访问白嫖社区允许的 HTTPS 地址。
