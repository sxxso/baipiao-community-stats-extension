# 白嫖社区个人统计插件设计规格

**日期**：2026-09-10  
**项目**：`baipiao-community-stats-extension`  
**状态**：已获用户确认，待实现计划评审

## 目标

创建一个独立的 Chromium Manifest V3 浏览器插件，用小弹窗展示当前登录用户在 `https://baipiao.org/bbs/` 社区里的个人资料、互动统计和最近活动。

插件与工作区内现有的 `newapi-checkin-edge-audit` 完全无关，不复用其代码、权限、存储键或品牌文案。

## 用户与核心流程

目标用户是已经在浏览器中登录白嫖社区的社区成员。核心流程如下：

1. 用户打开或保持一个 `baipiao.org` 页面并完成登录。
2. 用户点击插件工具栏图标。
3. 插件弹窗读取当前登录会话下可访问的个人资料和活动数据。
4. 弹窗在 3 秒内展示账号概览、互动统计和最近活动。
5. 用户可刷新数据，或跳转到社区个人主页查看完整内容。

密码、访问令牌和 Cookie 不由插件读取、保存、导出或上传。

## 功能范围

### 账号概览

展示当前账号可获得的以下信息：

- 用户名或显示名
- 头像
- 注册时间
- 信任等级；若站点返回等级名称和等级数值，优先展示名称并保留数值
- 最近活跃时间
- 个人主页入口

### 互动统计

展示站点个人资料或活动数据中明确提供的指标：

- 发布主题数
- 回复数
- 获得的赞
- 给出的赞
- 访问天数或阅读量（只有接口明确提供时才展示）

站点未提供的指标显示为 `—`，不能用猜测值或页面列表条目数冒充。

### 最近活动

展示最近 5 条可识别的主题发布或回复活动，每条包含：

- 活动类型：发布主题或回复
- 主题标题
- 分类名称（站点返回时展示）
- 相对时间或格式化时间
- 主题链接

点击活动条目时，在新标签页打开对应的社区主题页面。

### 活跃趋势

展示近 7 天的紧凑型活动趋势：

- 优先使用个人活动接口返回的时间序列数据。
- 如果只有带时间戳的最近活动记录，则按日期聚合活动数量。
- 没有足够数据时显示空状态和“暂无可用趋势数据”，不绘制误导性的零值趋势。

### 登录与异常状态

- 未登录：显示明确的登录提示和“打开社区登录”按钮。
- 页面会话失效：显示“登录状态已失效”，提供重新打开社区按钮。
- 数据接口暂时失败：保留已有缓存数据（若存在），在顶部显示刷新失败原因和重试按钮。
- 站点返回字段缺失：按字段降级显示，不让整个弹窗失败。
- 网络超时：在 3 秒内显示可理解的错误状态，不能无限加载。

## 技术架构

### 扩展组成

- `manifest.json`：Manifest V3 配置、图标、弹窗入口和最小权限。
- `popup.html`：弹窗语义结构。
- `popup.css`：弹窗布局、主题、响应式和可访问性样式。
- `popup.js`：渲染、用户操作、消息通信和状态管理。
- `background.js`：Service Worker，协调当前标签页、打开社区页面和消息分发。
- `content.js`：只注入 `baipiao.org` 页面，在页面同源上下文读取当前会话可访问的数据。
- `lib/data-adapter.js`：将站点资料、活动、统计接口的不同字段归一成插件内部模型。
- `lib/storage.js`：仅保存非敏感的最近一次成功统计结果、更新时间和界面偏好。
- `icons/`：独立插件图标资源。
- `tests/`：数据归一化、日期聚合、渲染状态和消息协议测试。

### 数据访问原则

采用“Service Worker + 社区页面 Content Script”方案：

1. 弹窗发送 `GET_PROFILE` 消息给 Service Worker。
2. Service Worker 查找当前窗口已有的 `baipiao.org` 标签页；没有时打开社区页面。
3. Content Script 在 `baipiao.org` 页面内使用浏览器已有登录状态请求公开或登录后可访问的社区数据。
4. Content Script 将去除 Cookie、密码和令牌的结构化结果返回给 Service Worker。
5. Service Worker 返回弹窗并写入非敏感缓存。

Content Script 不读取 `document.cookie`，不读取密码输入框，不把原始响应写入存储，不向第三方域名发送数据。

### 数据源策略

数据适配层按以下优先级获取数据：

1. 站点已公开提供、且当前页面可用的用户资料/活动接口。
2. 登录用户个人主页中的结构化 DOM 或嵌入状态数据。
3. 页面中可识别的最近活动链接和时间信息。

站点具体接口名称和字段不得硬编码成唯一来源；适配器需要接受缺失字段，并返回部分成功结果。实现阶段应以实际页面/响应为准确认字段。

### 内部数据模型

```js
{
  profile: {
    username: string | null,
    displayName: string | null,
    avatarUrl: string | null,
    trustLevel: number | null,
    trustLabel: string | null,
    joinedAt: string | null,
    lastSeenAt: string | null,
    profileUrl: string | null
  },
  stats: {
    topics: number | null,
    replies: number | null,
    likesReceived: number | null,
    likesGiven: number | null,
    daysVisited: number | null,
    views: number | null
  },
  activity: [
    {
      type: "topic" | "reply",
      title: string,
      category: string | null,
      timestamp: string | null,
      url: string
    }
  ],
  trend: [
    { date: "YYYY-MM-DD", count: number }
  ],
  fetchedAt: string,
  source: "api" | "dom" | "mixed"
}
```

## 弹窗设计

### 尺寸和信息层级

- 目标宽度：380px 左右。
- 首屏内容不依赖滚动：账号概览、四项核心统计、刷新操作可见。
- 最近活动区域可滚动，最多展示 5 条。
- 复杂数据不放入二级卡片或配置页，使用分组、分隔线和紧凑列表。

### 视觉方向

- 白色或浅灰背景，黑色文字。
- 橙色作为活跃/提醒强调色。
- 薄荷绿色作为成功和数据强调色。
- 细边框、低阴影、最多 8px 圆角。
- 使用系统无衬线字体，确保中文和英文混排稳定。
- 图标按钮使用项目内置的 SVG 图标资源或文本替代，并提供 `title`/`aria-label`。

### 可访问性

- 所有按钮可通过键盘访问。
- 刷新、打开主页、打开社区等图标按钮提供可访问名称。
- 加载、错误、未登录状态使用 `role="status"` 或 `role="alert"`。
- 支持 `prefers-reduced-motion`。
- 文本、数字和按钮在 380px 宽度下不发生遮挡或横向溢出。

## 权限与隐私

首版只申请实现所需的最小权限：

- `storage`：保存非敏感缓存和主题偏好。
- `tabs`：查找或打开 `baipiao.org` 页面。
- `scripting`：在目标页面注入或执行数据读取脚本。
- `host_permissions`：限定为 `https://baipiao.org/*`。

不申请 `<all_urls>`、`cookies`、`history`、`webRequest` 或远程代码权限。

缓存中不得出现 Cookie、密码、Authorization 头、完整 HTML 或原始响应体。刷新时只保存归一化后的数据和时间戳。

## 测试策略

### 单元测试

- 资料字段在不同命名格式下的归一化。
- 缺失字段降级为 `null`。
- 活动按近 7 天日期聚合。
- 主题发布和回复活动分类正确。
- 未登录、超时、部分成功、空活动列表状态正确。

### 集成测试

- Service Worker 与 Content Script 的消息协议。
- 当前标签页查找、打开社区页面和重试流程。
- `chrome.storage` 只写入非敏感归一化数据。
- 弹窗从加载到成功、未登录和错误状态的渲染。

### 手工验收

1. 在未登录状态点击插件，出现登录提示和社区入口。
2. 在已登录状态点击插件，3 秒内显示账号概览。
3. 点击刷新后更新时间变化，活动条目不重复。
4. 点击活动条目打开正确主题。
5. 断网或接口失败时不出现无限加载。
6. 检查权限清单没有超出本规格范围。

## 非目标

- 不实现自动签到、发帖、点赞、收藏、私信或任何会改变社区状态的操作。
- 不读取或导出 Cookie、密码、浏览历史或完整页面内容。
- 不建设服务器、用户账户体系或远程统计服务。
- 不修改现有 NewAPI 签到扩展。
- 不承诺站点未公开提供的精确历史统计。

## 验收标准

当用户在 `baipiao.org` 已登录时，点击独立插件图标可以在 3 秒内看到用户名、可用的个人统计和最近活动；刷新成功后数据更新时间更新；未登录或数据不可用时显示明确、可操作的状态；插件不请求无关域名、不保存敏感认证数据，并且现有 NewAPI 扩展目录没有文件变化。
