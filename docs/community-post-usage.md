# 分享一个白嫖社区个人统计插件：余额、等级、活动和资金记录一眼查看

最近做了一个白嫖社区个人统计插件，主要是方便查看一些分散在个人主页和资金记录页里的信息。插件目前支持 Chrome 和 Edge，源码和安装包都放在 GitHub，大家可以按自己的浏览器选择。

## 能看什么

点击浏览器工具栏里的插件图标，可以查看：

- 当前登录账号的用户名、头像、称号和加入时间
- 主题数、回复数、毛余额和社区等级
- 毛排行榜前 10 名和自己当前的名次
- 每日签到状态：今天是否已签、今日可得或已得的毛数、当月签到天数和已得毛数、签到档位和下一档
- 每日任务列表：任务名称、完成条件、奖励和完成状态，未完成的排在前面
- 最近 7 天活跃趋势
- 最近主题和回复活动

在白嫖社区页面右下角，还会有一个可以收起的小窗口，用来显示：

- 最近 5 条资金记录
- 每条记录的资金用途和时间
- 余额是增加还是扣除，以及变化金额
- 当前毛余额
- 毛排行榜前 5 名和自己的名次，点击“排行榜”可以打开完整榜单
- 今日签到状态和当月签到概况
- 最多 4 条每日任务和对应奖励

浮窗可以点击 `−` 收起，收起后点击 `+` 重新展开；点击 `↻` 可以手动刷新，点击“查看全部”可以打开网站原始资金记录页，点击“签到”可以打开签到页面。今天还没签到时，浮窗的签到区域会出现「一键签到」按钮，点击即可完成当天签到并自动刷新毛余额。

## 重要说明

现在打开插件弹窗时只读取浏览器本地缓存，不会自动刷新。需要读取最新数据时，点击弹窗右上角的刷新按钮即可。

资金记录、最近活动、毛排行榜、每日签到和每日任务都是通过白嫖社区的接口直接读取的，在任何社区页面点刷新都能获取，不需要先打开个人主页、资金记录页、排行榜页、签到页或任务页，也不需要等待页面额外加载。毛余额刷新时优先读取 `/bbs/api/users/<用户ID>` 的 `money` 字段；资金流水接口只提供交易行，管理员调账等没有流水的变化也会正确反映。毛排行榜读取 `/bbs/api/money-rank`，展示前若干名、自己的名次和全站有毛的账号数；每日签到读取 `/bbs/api/bp/checkin`（需要登录，读取状态；点击「一键签到」时向同一地址提交一次当天签到请求），每日任务读取 `/bbs/api/quest-infos`，只读取任务公开字段。用户接口、签到接口暂时不可用时会回退到页面内嵌数据或保留上次成功读取的结果，排行榜接口暂时不可用时会保留上次成功读取的榜单；整个刷新请求失败时才保留上次成功缓存。

弹窗里的签到卡片是只读展示，只显示状态并提供跳转链接；签到操作只发生在右下角浮窗的「一键签到」按钮上：只有你本人点击后，插件才会向社区的签到接口（`/bbs/api/bp/checkin`）提交一次当天签到请求，请求带同源登录会话和 CSRF 令牌，今天已签、暂不可签到或未登录时按钮不会出现。插件不会自动签到，也不会代替你领取每日任务奖励。

## 安装方法

GitHub 仓库：

https://github.com/sxxso/baipiao-community-stats-extension

直接下载：

- Edge：<https://github.com/sxxso/baipiao-community-stats-extension/releases/latest/download/baipiao-community-stats-extension-edge.zip>
- Chrome：<https://github.com/sxxso/baipiao-community-stats-extension/releases/latest/download/baipiao-community-stats-extension-chrome.zip>

下载对应压缩包后解压：

1. 打开 Edge 的 `edge://extensions/`，或 Chrome 的 `chrome://extensions/`。
2. 开启“开发人员模式”或“开发者模式”。
3. 点击“加载解压缩的扩展”或“加载已解压的扩展程序”。
4. 选择解压后第一层直接包含 `manifest.json` 的目录。
5. 打开白嫖社区并登录，然后刷新网页。

Edge 如果提示找不到清单文件，通常是目录选错了。不要选择 ZIP 文件或外层下载目录，继续进入内层，直到能直接看到 `manifest.json`。

## 安全性

插件只在 `https://baipiao.org/bbs/` 范围内读取当前登录账号已经可以看到的资料，不执行发帖、回复、点赞、收藏、私信、转账等操作。唯一的写操作是右下角浮窗的「一键签到」：由你本人点击触发，向社区签到接口提交一次当天签到请求，不会自动执行，也不会代替你领取每日任务奖励。

插件不读取 `document.cookie`、密码输入框或网站 `localStorage`，不保存和上传密码、Cookie、Authorization、Token、完整 HTML 或原始响应。归一化后的统计快照、最多 5 条资金记录，毛排行榜前 10 名的公开榜单字段（排名、用户名、余额、主页链接），以及每日签到的公开状态（今日是否已签、今日奖励、当月签到天数与已得毛数、签到档位）和每日任务的公开字段（名称、说明、完成条件、奖励、是否每天可做、是否已完成）只保存在当前浏览器本地，不会上传到作者服务器；排行榜不保存他人头像或原始响应，任务不保存图标样式或原始响应。

唯一的第三方请求是新版本检查：插件约每 6 小时节流访问一次 GitHub 公开接口，读取本仓库最新 Release 的版本号，不携带任何账号或社区数据。发现新版本时弹窗会提示并可一键打开发布页；“加载解压缩的扩展”受浏览器限制无法静默替换文件，升级仍需下载解压后重新加载。

安装前建议检查扩展的 `manifest.json`，确认权限只有 `storage`、`tabs`、`scripting`，网站范围只有 `https://baipiao.org/bbs/*`。源码公开在 GitHub，大家可以自行审查。

## 遇到问题

白嫖社区响应较慢时，插件会保留上次成功读取的数据。可以先刷新社区页面，等待加载完成，再点击插件右上角的刷新按钮。

如果资金记录为空，可以点击浮窗里的“查看全部”，确认网站原始资金记录页是否有数据。网站改版后如果页面结构变化，也可能需要更新解析规则。

欢迎试用。如果发现数据不对、读取超时或 Edge/Chrome 安装问题，可以在帖子下面反馈浏览器、页面位置和具体提示，尽量不要贴出账号 Cookie、密码或 Token。
